1.Set Laravel Public Directory as Document Root
------------------------------------------------------------------
	C:\xampp\apache\conf\extra\httpd-vhosts.conf

	<VirtualHost *:88>
    		DocumentRoot "C:/xampp/htdocs/h-rims/public" 
    		<Directory "C:/xampp/htdocs/h-rims/public">
        		AllowOverride All
        		Require all granted
    		</Directory>
	</VirtualHost>

	# disable directory browsing 
		C:\xampp\apache\conf\httpd.conf
			Options All -Indexes
			listen 88
#################################################################
2.Enable mod_rewrite and Restart Apache
-----------------------------------------------------------------
	LoadModule rewrite_module modules/mod_rewrite.so
#################################################################
3.Clone the repository (first time only)
-----------------------------------------------------------------
	git clone https://github.com/xmodify/h-rims.git rims
	cd rims
#################################################################
4.Pull latest changes (if already cloned)
-----------------------------------------------------------------
	git pull origin main
#################################################################
#################################################################
5.Install PHP dependencies
-----------------------------------------------------------------
	composer install --no-dev --optimize-autoloader

#################################################################
6.ติดตั้ง Node.js (สำหรับบอท e-Claim ThaiD & KTB EDC)
-----------------------------------------------------------------
	- ดาวน์โหลดและติดตั้ง Node.js (LTS Version) จาก https://nodejs.org
	- เมื่อติดตั้งเสร็จ ให้เปิด CMD/PowerShell ทดสอบด้วยคำสั่ง:
		node -v
		npm -v
	- ระบบ Windows มี Microsoft Edge อยู่แล้ว หรือติดตั้ง Google Chrome เพิ่มเติมได้

#################################################################
7.ติดตั้ง Python 3 (สำหรับอ่านไฟล์ .mdb / .accdb ของ AIPN)
-----------------------------------------------------------------
	- ดาวน์โหลดและติดตั้ง Python 3 จาก https://www.python.org
	- **สำคัญ**: ในหน้าติดตั้งให้ติ๊กถูกที่ช่อง [✔] "Add python.exe to PATH"
	- เปิด CMD แล้วรันคำสั่ง:
		pip install access-parser

#################################################################
8.Setup your .env file
-----------------------------------------------------------------
	cp .env.example .env
	php artisan key:generate
	แก้ไขค่า DB, URL ในไฟล์ .env

#################################################################
9.ปิดการใช้งาน push ด้วย Git hook (เฉพาะเครื่อง)
----------------------------------------------------------------
	9.1 สร้างไฟล์ pre-push ที่โฟลเดอร์ .git/hooks/:
		touch .git/hooks/pre-push
		chmod +x .git/hooks/pre-push
	9.2 ใส่โค้ดใน pre-push เพื่อบล็อกทุกการ push:
		nano .git/hooks/pre-push
			#!/bin/sh
			echo "❌ git push ถูกบล็อกไว้ ห้าม push ไปยัง GitHub"
			exit 1

#################################################################
กรณี Update โค้ดบน Windows XAMPP
----------------------------------------------------------------
	git reset --hard && git pull origin main
	composer install --no-dev --optimize-autoloader
	php artisan optimize:clear
