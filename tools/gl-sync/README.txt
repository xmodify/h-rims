========================================================================
     คู่มือการติดตั้งและใช้งาน H-RIMS GL Sync Agent (Go Microservice)
========================================================================

โปรแกรมนี้เป็น Microservice สำหรับเชื่อมต่อข้อมูลระหว่างโปรแกรมบันทึกบัญชี
โรงพยาบาล (MS Access: GL69.accdb) เข้าสู่ระบบ H-RIMS แบบอัตโนมัติ

คุณสมบัติ:
1. ทำงานแบบ Read-Only ไม่รบกวนและไม่ล็อกไฟล์ ขณะที่เจ้าหน้าที่กำลังลงบัญชี
2. ส่งข้อมูลผังบัญชี, ใบสำคัญ, รายการเดบิต/เครดิต, ทะเบียนเจ้าหนี้-บิลค้างจ่าย
3. ใช้ทรัพยากรเครื่องน้อยมาก (แรม < 15MB) และทำงานได้อย่างรวดเร็ว

------------------------------------------------------------------------
ขั้นตอนการติดตั้งและตั้งค่า:
------------------------------------------------------------------------

1. แก้ไขไฟล์ "config.json" ด้วย Notepad:
   - "api_url" : URL ของระบบ H-RIMS เช่น "http://192.168.1.10/rims/api/hosfin/gl/sync"
   - "api_token" : Token สำหรับยืนยันตัวตน (ค่าเริ่มต้น: "rims-gl-token-2569-secret")
   - "db_path" : ตำแหน่งไฟล์ Access ในเครื่องการเงิน เช่น "D:\\GL\\GL69_huataphangospital.accdb"
   - "sync_interval_minutes" : รอบเวลาที่ต้องการให้ซิงค์ข้อมูล (เช่น 30 นาที)

2. ทดสอบการทำงาน:
   - ดับเบิ้ลคลิกไฟล์ "run-manual.bat"
   - หน้าจอจะแสดงขั้นตอนการอ่านข้อมูลจาก Access และส่งข้อมูลไปยัง H-RIMS
   - หากขึ้น [SUCCESS] แสดงว่าการเชื่อมต่อถูกต้องสมบูรณ์

3. ตั้งเวลาให้ทำงานอัตโนมัติ:
   - คลิกขวาที่ไฟล์ "install-scheduler.bat" แล้วเลือก "Run as Administrator"
   - ระบบจะสร้าง Windows Task Scheduler ให้ทำงานอัตโนมัติทุกๆ 30 นาที

4. การยกเลิก:
   - ดับเบิ้ลคลิกไฟล์ "uninstall-scheduler.bat" เพื่อยกเลิกงานตั้งเวลา

------------------------------------------------------------------------
ทีมพัฒนาระบบ H-RIMS Platform
