========================================================================
     คู่มือการใช้งาน H-RIMS GL Sync Agent (Rims-GL-Sync.exe)
========================================================================

โปรแกรมนี้เป็น Standalone GUI Application สำหรับเชื่อมต่อข้อมูลระหว่าง
โปรแกรมบันทึกบัญชีโรงพยาบาล (MS Access: GL69.accdb) เข้าสู่ระบบ HosFin Dashboard แบบอัตโนมัติ

คุณสมบัติ:
1. หน้าต่าง GUI สวยงาม ดับเบิ้ลคลิกใช้งานได้ทันที มีปุ่ม Browse เลือกไฟล์ GL
2. รองรับ Auto-Start เริ่มต้นทำงานอัตโนมัติเมื่อเปิดเครื่องคอมพิวเตอร์
3. รองรับ Auto-Schedule ซิงค์ข้อมูลเบื้องหลังตามรอบเวลาที่กำหนด (เช่น ทุก 30 นาที)
4. ทำงานใน System Tray ย่อเก็บข้างแถบนาฬิกาได้ พร้อมระบบ Single-Instance ป้องกันการเปิดซ้ำ
5. ทำงานแบบ Read-Only ไม่รบกวนและไม่ล็อกไฟล์ ขณะที่เจ้าหน้าที่กำลังลงบัญชี
6. ส่งข้อมูลผังบัญชี, ใบสำคัญ, รายการเดบิต/เครดิต, ทะเบียนเจ้าหนี้ AP, ลูกหนี้ AR, ต้นทุน LC/MC/CC

------------------------------------------------------------------------
ขั้นตอนการใช้งาน:
------------------------------------------------------------------------

1. ดับเบิ้ลคลิกที่ไฟล์ "Rims-GL-Sync.exe" เพื่อเปิดโปรแกรม
2. กำหนดค่า:
   - API Sync URL: ใส่ URL เช่น "http://127.0.0.1/rims/api/hosfin/gl/sync"
   - API Token: ใส่ Token (เช่น "rims-gl-token-2569-secret")
   - กดปุ่ม "ทดสอบเชื่อมต่อ" เพื่อตรวจสอบว่าติดต่อ Server ได้สมบูรณ์
   - กดปุ่ม "Browse..." เพื่อเลือกไฟล์ GL (.accdb) ในเครื่อง
   - ติ๊กถูกที่ "เริ่มทำงานอัตโนมัติเมื่อเปิดเครื่อง (Auto-Start)"
   - ติ๊กถูกที่ "เปิดใช้งานการส่งตามรอบเวลาอัตโนมัติ (Background Schedule)"
3. กดปุ่ม "บันทึกการตั้งค่า (Save)"
4. กดปุ่ม "ซิงค์ข้อมูลทันที (Sync Now)" เพื่อทดสอบส่งข้อมูลครั้งแรก
